## 🚀 Express Deploy (5 Minutes)

### Prerequisites
- Docker installed
- 4GB RAM available
- Terminal access

### Steps

```bash
# 1. Clone/download this repository
git clone https://github.com/adampielak/awesome-wazuh.git
cd awesome-wazuh

# 2. Set your own passwords (12 to 64 characters, upper and lower case,
#    a digit and one of . + -); .env is git-ignored
cd examples/docker-compose
printf 'INDEXER_PASSWORD=%s\nWAZUH_API_PASSWORD=%s\n' '<indexer-password>' '<api-password>' > .env

# Start the stack
docker-compose up

# 3. Wait for containers to start (~2-3 min)
# You'll see: "wazuh" | [info] Wazuh v4.x.x started

# 4. Access the dashboard
# URL: https://localhost:443
# Username: admin
# Password: the INDEXER_PASSWORD you set in .env
```

### What's Running?
- ✅ Wazuh Manager (threat detection)
- ✅ Wazuh Indexer (log storage)
- ✅ Wazuh Dashboard (visualization)

**Next**: Deploy agents from [Deployment Guide](../deployment/index.md)

## 🔒 Security Checklist

Before deploying to production:

- [ ] Change default passwords
- [ ] Enable SSL/TLS certificates
- [ ] Configure RBAC (role-based access control)
- [ ] Enable audit logging
- [ ] Configure backup strategy
- [ ] Review retention policies
- [ ] Enable multi-factor authentication
- [ ] Configure firewall rules
- [ ] OS hardening (CIS benchmark)
- [ ] Enable monitoring for Wazuh itself
